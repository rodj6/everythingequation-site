Two features of Definition 4.1 deserve comment.

First, the factorizations (4.2) are exactly requirements (1) and (2) of Definition 2.2: the readout survives, and every nominated relation is a function of the completed state.

Second, surjectivity of eee is not a technical convenience but a substantive part of the definition, and it is what makes the universal property come out uniquely. A completed state that no source state realizes is not a state of the system; it is a spurious element. If unrealized elements were permitted, then given any sufficient EEE one could adjoin an arbitrary point ∗\ast∗ with arbitrary values u(∗)u(\ast)u(∗) and ραE(∗)\rho_\alpha^E(\ast)ραE​(∗) (subject to nothing, since (4.2) constrains only the image of eee), and the map to EAE_AEA​ would no longer be determined: the value ϕ(∗)\phi(\ast)ϕ(∗) would be unconstrained by eA=ϕ∘ee_A=\phi\circ eeA​=ϕ∘e. Uniqueness in Theorem 5.1 would fail. Surjectivity excludes exactly this, and it does so for the honest reason: a completion consists of states realized by source states.

We display (4.4) rather than merely deducing it, because it records what a morphism of completions actually preserves: the readout and every nominated relation value. What is not imposed is any compatibility beyond that, no metric, no ordering, no choice of labels.
