Verification, reciprocal status and limits

The supplied code compiles sparse vector Walsh data to a basis and an exact frequency-coordinate certificate. Verification checks 254 response instances, 6060 complete small parity-map tests against independent fibre equality, direct source-word enumeration for lengths one through seven, and exact agreement of the two integer DPs through length 256. It also checks the Hamming-weight counterexam-ple to unrestricted nonlinear minimality. The code is a conventional exact preprocessor and reference algorithm; it is not the paper’s external ETH counter or contraction routine. This supplies an explicit answer to the reciprocal question at a restricted level: target-relative completion can remove unnecessary summary detail and improve a declared weighted calculation without recovering its full response distribution. It does not prove a new general ETH exponent, improve the best known algorithm for this simple Markov family, or show that the ETH paper overlooked a universally smaller sufficient summary. To use the parity quotient inside that paper’s own recursive Taylor/mode computation, one would additionally need a factorization and coefficient certificate at every transformed node. No such universal claim is made. The result changes computational organization, not physical access. No individual hidden source bit becomes readable through faster marginal calculation. The source, Markov law, independent noise, target projection, clock and unread-record permissions remain assumptions. No quantum resource minimum, Born-selection law or consciousness condition changes.
