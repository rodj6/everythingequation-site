Constructive obstruction and minimum-cost predictive completion

Target descent and the coarsest sufficient extension provide the information criterion used below. This section adds an exact finite compiler, a minimum-cost realization procedure within a specified sensor menu, and an analytically solved nonlinear dynamical family. Its ETH consequence is conditional on the supplied counting theorem. The executable backend is a conventional bounded-cache DPLL counter, not an implementation or practical speed demonstration of that theorem. The abstract criterion and coarsest joint-image completion are already established in Rodgers’s target-relative completion papers[10, 11]. The algorithms below realize that criterion within finite circuit and menu representations. The finite synchronous application is not an extension of the Hilbert-space analytic hypotheses of projected-dynamics theory.

Theorem 2.3 (Exact minimum-cost completion synthesis). With exact optimization and separation, this algorithm terminates and returns either a globally minimum-cost sufficient feasible selection or a sound impossibility result within the declared menu/family. Proof. Every true sufficient selection separates every returned target-disagreeing pair, so it satisfies every accumulated cut. The current restricted optimization value is therefore a lower bound on the true optimum. This is an application of established counterexample-guided synthesis and implicit hitting-set optimization, not their invention. All source states are admissible. The target is the next observed bit, which depends globally and nonlinearly on the source. The permitted readers are the individual hidden-bit ports 0, and disjoint pair-parity ports. A direct global target reader is not in the menu. The source is a declared synchronous classical logic model. The ports read the same classical register nondestructively; joint measurement is therefore admitted. The task predicts the future from records acquired before the first update; waiting to observe the target after that update does not satisfy the prediction task. Only the stated present-time ports are admitted. No laboratory prediction-deadline or timing advantage is certified by this discrete model. A pair-parity port is a separately admitted two-bit reader with a specified cost, not a free computational substitute for physically inaccessible bits. Clock, fixed logic and archival choices are external specified resources. No energy, continuous-time or quantum efficiency conclusion follows from the cost units.

Implementation, verification and scope

The implementation consists of completion.py and verify_finite.py. It uses exact inte-gers/Fractions and a conventional DPLL counter with a cache bounded to 4096 states. It includes truth-table circuit compilation, a two-copy obstruction oracle, compatible target counts, exact finite-prior reference calculations, menu constraints, reoptimized synthesis and explicit incomplete/empty-source statuses. Inputs with malformed bits, sensor indices, costs or negative prior weights are rejected. Nonuniform prior tables are globally validated, including entries outside the queried fibre. The tests compare randomized CNF counts, unique gate extensions, random nonlinear constrained models, every sensor subset, compatible target counts and finite optima against direct source enu-meration. They also cover empty sources, impossible readouts, empty targets, infeasible hardware constraints and early stopping. The independent audit uses a distinct source-enumeration implemen-tation. Numerical runtime measurements describe this prototype only; no ETH-backend speedup is claimed. This work adds a constructive finite synthesis interface and a sharp menu-constrained dynamical example to the supplied baseline. Continuous CP feasibility is not replaced by an unrestricted Boolean decision problem. Source identification, source accessibility and source counting remain distinct.
