External-theorem dependency and reproducibility

Reproduction. The top-level build.py builds this manuscript in a disposable source copy. re produce.py--check validates the scoped input hashes, Python syntax and local-module closure; reproduce.py--outputPATH runs the declared checks in a disposable expanded tree and retains per-job receipts, logs and products. The supplement’s evidence guide distinguishes original arithmetic/certificate checks from focused input-schema regressions. Assertions are part of the verification contract: optimized Python execution with -O is rejected by the runner and public certificate module.
