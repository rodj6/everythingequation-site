Finite-horizon resource accounting: what survives beyond the memory box

An exact streaming advantage survives the expanded accounting, but it is an advantage in reusable causal memory, not a claim that an entire closed apparatus has four dimensions. For the noiseless trine process and any declared horizon4, four quantum dimensions and nine classical states are the exact causal-memory minima when every history-correlated controller, reference and environment that can influence the future is included at the causal cut. In contrast, the retained archive and an isometric implementation of its classicalization require resources growing with the horizon. These resources can be calculated exactly for the supplied quantum construction. This corrects a possible overreading of the earlier four-versus-nine result. The calculation concerns ordinary finite-dimensional instruments and exact channels. It assumes Born probabilities, does not select actual events, and does not assign hardware size, energy, temperature or a physical reset cost to a Hilbert dimension. The preparation, interface and accuracy must be the same for every comparison; the finite-accuracy comparator elsewhere in this companion changes the appropriate conclusion when an exact law is unnecessary.
