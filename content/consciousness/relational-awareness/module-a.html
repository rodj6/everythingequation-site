Adequate sources, quotients and calibrated identification

A description earns its adequacy by preserving the distinctions the investigation actually needs. Returning the right answer on one task is not enough to identify the source of a presentation. This chapter develops the exact tests: continuation, common decoding, calibrated equality, native dependence and full-law comparison.

A physical description can preserve a response while omitting variables needed for another response or for its interpretation. Adequacy is therefore assessed relative to specified ports, preparations and readers. A quotient or statistic is not promoted to an experiential bearer merely because it is sufficient for one task. These distinctions develop the programme’s source and intrinsic-grain analysis (Rodgers, 2026h,i).

1.3 Exact qualitative equality certificates

Suppose independent calibration supplies exact same/different qualitative judgments on nominated tokens. Collapse the same-judgment components; different judgments give edges of a graph on the remaining kkk components. Compatible qualitative partitions are precisely its proper colorings, with arbitrary unrestricted labels. Such data uniquely specify the partition if and only if this graph is complete: a missing edge permits those two components to merge; a complete graph forbids every merge. Autonomy can add equalities through continuation, but a report code alone cannot add calibration.

For nnn original tokens and kkk classes the smallest certificate has n−k+(k2)n-k+\binom{k}{2}n−k+(2k​) comparisons. Every class needs a connected equality graph, requiring its size minus one edges; each pair of classes needs an inequality. Spanning trees and one inequality per pair attain the lower bound. A fixed known number of qualitative labels imposes a different coloring problem and is not assumed here.

1.4 Native dependency and source fibres

Let F:∏iSi→∏jSjF:\prod_iS_i\to\prod_jS_jF:∏i​Si​→∏j​Sj​ be a finite bijection with full Cartesian preparation support and nontrivial native ports. Join input iii to output jjj when varying only iii can change FjF_jFj​. The bipartite essential-dependency components give the unique finest routed factorization. Each output depends only on inputs in its component, so a product decomposition exists. Global injectivity and surjectivity force each component map to be bijective. Any other routed product cannot split an essential edge, proving fineness and uniqueness. For two bits, eight of the 24 bijections are products of local flips and a possible swap; sixteen are prime. Global mixed recoding is not native gauge: it can conjugate a swap to a controlled-XOR update while failing independent local clamp correspondence (Module B).

A downstream component without a return path into the executive component cannot alter that component’s kernels. The directed dependency graph’s return-strongly-connected component supplies a physical prefilter, not a phenomenal-inertness theorem for spectators.

For a graph on nnn source bits, edge parities xi⊕xjx_i\oplus x_jxi​⊕xj​ have incidence rank n−cn-cn−c over F2\mathbb F_2F2​, where ccc is the number of connected components. The kernel consists exactly of vectors constant on each component, hence has 2c2^c2c members. One source-bit anchor per component removes this ambiguity. Strong pair dependency does not entail a scalar triple term: the period-four map (a,b,c)↦(c,a⊕c,b⊕c)(a,b,c)\mapsto(c,a\oplus c,b\oplus c)(a,b,c)↦(c,a⊕c,b⊕c) has a strongly connected dependency graph while every coordinate depends on at most two inputs. The graph is an organization descriptor, not an identified qualitative relation.
