Proof. We prove by induction on dim_{K} W that L ∩W is a finitely generated abelian group for every K-subspace W ⊆V . The assertion is immediate for W = 0. Otherwise choose 0 ̸= x ∈W and a functional from (C.20). The kernel of its restriction to W is proper, because it does not contain x, so its dimension is smaller. The image of L ∩W is an additive subgroup of 𝒪_{Kx}. This ring is a finitely generated free abelian group, hence is noetherian as a ℤ-module; its subgroup is finitely generated. Its kernel is L ∩(W ∩ ker ϕ_{x}), which is finitely generated by induction. Lift a finite set of image generators and add a finite set of kernel generators. Every element of L ∩W subtracts an integer combination of the former to leave an element of the kernel, so this combined finite set generates it over ℤ. Taking W = V gives finite abelian generators of L. Their 𝒪_{K}-span is contained in L, and contains their ℤ-span L, so they also generate L over 𝒪_{K}. This is exactly the source’s dimension induction; no common field for all the functionals is assumed.

Proof. The set M of elements with all valuations nonnegative is an 𝒪_{K}-submodule. Each g ∈S belongs to its K-span, because g = a^{−}_{g}^{1}(a_{g}g). Thus f^{k+1} belongs to that span. Express it as a finite linear combination of members of M and clear the scalar denominators by a single nonzero t ∈𝒪_{K}. Then tf^{k+1} ∈M. Fix one valuation. If v(f) = +∞, then also v(tf) = +∞. Otherwise put b = v(f) ∈ℝ and c = v_{𝔭}(t) ≥0. We know c+(k +1)b ≥0. If b ≥0 then c+b ≥0; if b < 0 then c+b ≥c+(k +1)b ≥0. Hence v(tf) ≥0 in both cases, for the same scalar t at every prime and every valuation. Taking a = t proves the assertion.
