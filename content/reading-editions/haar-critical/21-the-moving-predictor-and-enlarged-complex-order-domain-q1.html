Interval evaluation followed by multiplication by cell volume encloses the integral on each cell. The implementation sums outward interval endpoints as exact dyadics before the final ball conversion. The sum of widths tends to zero: for fixed r each elementary operation, including the clipping operations, has a uniformly continuous interval extension on its input enclosure, and working precision can increase as the angular mesh shrinks. One can equivalently use a finite bound on the derivatives of the smooth factors and the explicit Lipschitz norm of the cutoff. Thus first choose r so that the discarded integral fits its budget, then refine mesh and arithmetic until the remaining budget is met. There is no separate source, Mellin image or terminal truncation in this direct representation. Its cutoff, angular and arithmetic errors are all refined. This terminates at every requested absolute tolerance.

If the output disk is D(m, E), a validated ℓ≤|m| with ℓ> E returns the relative bound E/(ℓ−E). For a fixed nonzero value, as the absolute radius is driven to zero the modulus lower bound can be refined to the true modulus, so this rule eventually certifies the target. In contrast, a disk containing zero establishes only the additive bound. To evaluate very close to a zero, the local atlas and the adaptive source and image routes in Section 21 remain useful because the direct fallback can require very fine angular meshes. A bounded resource request can exhaust either method without deciding divergence or exact vanishing.
