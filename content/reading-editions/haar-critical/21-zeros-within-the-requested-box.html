Execution scope and practical companion.

The preceding computation executes the bound construction, not all of the finite moments on a continuum. The rank-four common formula is intentionally conservative and long. A useful practical algorithm should select a much shorter input-dependent filter and then check its own source, image, arithmetic and readout errors. A proof that a finite formula has a uniform absolute error is not an unconditional finite-arithmetic relative guarantee.

The new terminal_hybrid.py implements the complementary pointwise selection. It exposes design(N,z,s, h,delta,cap,goal) and bound(N,z,h,s,delta,operation). The operation includes the actual filter, chart, population if any, and direction/spectral panel counts. Every proposed schedule is evaluated in outward arith-metic. Warm orders must call bound again; an incoming inverse-order allowance is not reused for a different order. The complete sampler must also reprice folded aliases and all other budgets. The native integration and its cold/warm receipts are recorded in the practical verification section; a terminal-design receipt alone is not an end-to-end certificate.

The design menu tests the signed-gap representation away from an exact wall and low-clipping core charts as well as the inherited charts. It rejects invalid contours rather than changing branches. If no candidate meets the target before the resource cap, it returns the best finite allowance with goal_met=false, or raises an explicit resource exception when none is valid.
